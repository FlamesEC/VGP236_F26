# VGP236 (Fall 2026) PROJECT ARCHIVE

An archive of all projects currently done by [FlamesEC](https://github.com/FlamesEC) for the **VGP236** class at **LaSalle College Vancouver** using **Unity**, next to their respective executables.

(For more executable projects, feel free to check my [itch.io](https://flamesec.itch.io/))

# CONTENTS:

## "PACHINKO - IntroUnityLaSalle"
Simple **Pachinko-Styled Project** with the purpose of testing default **Unity Physics**.

### Contains:
* **Basic Rigidbody2D Usage**, for gravity and bouncing-related actions.
* **Class Inheritance**, for expandable obstacle implementation.
* **Loopable Gameplay**, through a repeatable game-scene.
* **Leaderboard Json-Based System**, for score tracking.

*( **A Simple Diversion** by **[Toby Fox](https://www.youtube.com/watch?v=p1U5FjgwDhA)**, not included in project files. )*

## "2D COOP PLATFORMER - hw2_platformer"
**Two-Player Cooperative Platforming Prototype**, consisting of multiple levels that test the communication and deduction capabilities of both players. 

Made with the purpose of further understanding **Unity's Input System**, **Rigidbody Usage**, and the creation of **Smooth Gameplay**.

### Contains:
* **Unity's Input System**, for 2-player separate input and controller support.
* **Custom Input Supporting Class**, for easier Input Buffering in relation to the Input System.
* **Local Multiplayer Manager**, for connecting and disconnecting support and assigning to player objects.

![2D COOP PLATFORMER gif](resources/gif_hw2.gif)

## "[UNTITLED PLATFORMER PROTOTYPE](https://flamesec.itch.io/3dplat) - hw3_3dtimerplatformer"
**Single Player 3D Platformer** consisting of a short minute-long level with Smooth 3D Movement, and a timer.

### Contains:
* **Unity's Animation System**, with Additive Animations and Blend Trees.
* **Custom Unity Transform Inheritance**, for further Rigidbody Inheritance Control through Velocity Additions & Rotation Support.
* **3D Velocity Rigidbody Usage**, with directional consideration & direction locking on specific circumstances.
* **ProBuilder**, for level blocking and quick iteration.
* **WebGL Desktop & Mobile Support**, for web-based usage.
